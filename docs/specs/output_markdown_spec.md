# 出力Markdown セクション構成（草案）

本構成はPhase 1のCLI出力を想定する。

## 1. ファイル構成

- ファイル名: `YYYYMMDD_{テーマ短縮}_{count}papers.md`
- 文字コード: UTF-8

## 2. セクション構成

1. タイトル
   - 例: `# {テーマ名} ブレインストーミング出力`
2. 入力サマリ
   - テーマ概要
   - 目的 / 問題意識
   - 前提・仮説
   - スコープ
3. 目次（任意）
4. セクションA: 関連度が高い論文（100本）
5. セクションB: 広域探索（200本）
6. セクションC: 無関係論文（200本）
   - C-1 反証・対立仮説（50）
   - C-2 測定・評価の地雷（50）
   - C-3 手法転用（50）
   - C-4 制約条件が真逆（50）
7. 付録（任意）
   - 生成条件（取得日・検索条件・フィルタ）

## 3. 論文単位の出力フォーマット

```
- タイトル: {title}
- 年: {year}
- 掲載: {venue}
- 被引用: {cited_by_count}
- リンク: {doi | openalex_url}

1) 関係性: {テーマとの関係性1文}
2) 要約: {abstract要約2〜3文}
3) 注意点: {前提/転用制約/反証可能性のいずれか}
```

## 4. 最小必須フィールド

- title
- year
- venue
- cited_by_count
- link (doi or OpenAlex)
- relationship
- abstract_summary
- caution

## 5. 省略ルール

- abstract欠損時: 要約文を省略せず、`要約: abstract欠損`と明記
- doi欠損時: OpenAlexリンクを使用
- cited_by_count欠損時: `被引用: 不明`

## 6. 無関係論文セクションの4章割り当てロジック（最小）

1. 無関係論文を入力順に保持する。
2. 4章にラウンドロビンで割り当てる。
3. 1章あたりの件数差は最大1件まで許容する。

## 7. 3行構成テンプレートの生成ルール（最小）

1. 関係性: テーマとの関連を1文で説明する。
2. 要約: abstractを2〜3文で要約する（abstract欠損時は欠損と明記）。
3. 注意点: 前提/制約/反証可能性のいずれかを1文で記載する。

## 8. 1テーマ=1Markdownの出力整形（最小）

- 1つのテーマ入力につき、1つのMarkdownファイルを出力する。
- ファイル名は `YYYYMMDD_{テーマ短縮}_{count}papers.md` に従う。
- `{テーマ短縮}` はタイトル先頭を英数小文字化し、空白を `_` に置換する。
