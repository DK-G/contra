# 品質評価観点（Phase 1）

本ドキュメントは、出力の品質を評価するための最小観点を定義する。

## 1. 関係性（強引さの許容範囲）

- **評価目的**: 「テーマとの関係性」が明示されているかを確認する。
- **観点**:
  - 直接関係がなくても、関係づけの軸が明確か
  - どの前提・観点・変数で結びつけたかが書かれているか
  - 無関係セクションでも“危険ポイント”が読み取れるか
- **NG例**:
  - 関係性が抽象的すぎて再現できない
  - テーマと論文の接点が不明瞭

## 2. 要約（忠実性）

- **評価目的**: Abstract要約が原著の内容に忠実かを確認する。
- **観点**:
  - 主張・方法・結果が抜け落ちていないか
  - 解釈や過剰な一般化が入っていないか
- **NG例**:
  - 主張が誇張されている
  - 本来の結論と逆のニュアンス

## 3. 注意点（転用/反証可能性）

- **評価目的**: 注意点が前提条件・転用制約・反証可能性に寄っているかを確認する。
- **観点**:
  - 「どこが危ないか」が明示されているか
  - 転用の制約が具体的か
- **NG例**:
  - 注意点が一般論になっている
  - 再現・検証の観点が欠けている

## 4. セクションバランス

- **評価目的**: 関連/広域/無関係の比率意図が守られているかを確認する。
- **観点**:
  - 100/200/200の比率が維持されているか
  - 無関係4章のバランスが極端に偏っていないか
- **NG例**:
  - 無関係セクションに関係論文が混入
  - 章ごとの偏りが極端

## 5. 再現性（同入力の安定性）

- **評価目的**: 同一入力に対して安定した構成が得られるかを確認する。
- **観点**:
  - セクション数や順序が崩れない
  - 出力形式が毎回変わらない
- **NG例**:
  - 出力順が毎回変動する
  - セクションが欠落する
