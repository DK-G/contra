# モバイルゲームUX・行動分析 contra 視座拡張レポート

## 入力サマリ

- テーマ概要: 数独を含むカジュアルパズルアプリの継続率向上を目的として、UX施策（難易度調整、オンボーディング、再訪導線、学習カーブ設計、失敗体験の緩和）の効果を体系的に整理したい。特にD7/D30を押し上げる要因として、初期の成功体験と中盤以降の成長実感がどのように設計されているかに関心がある。さらに、D1改善も中長期継続の上限を規定する可能性があるため、初回体験から1週間までの離脱要因を抽出し、パズルの生成難易度・ヒント設計・連続達成バッジ・通知/再開導線などの施策がどの程度効果を持つかを把握したい。
- 目的: カジュアルパズルアプリにおける継続率（D1/D7/D30）を改善するUX施策の効果を整理する
- 問題意識: 継続率はプロダクト改善と収益性の両方に直結し、改善余地の特定が重要なため
- アプローチ: application
- 前提・仮説:
  - 初期の成功体験がD1の上限を規定する
  - 難易度の段階設計がD7/D30の成長実感に影響する
  - ヒント/救済設計は離脱率を左右する
  - 再訪導線（通知・連続記録）が中長期継続に影響する
- スコープ:
  - 分野: モバイルゲームUX・行動分析
  - スケール: small
  - 時代: last_10_years
- include: casual puzzle, mobile game, user retention, difficulty adjustment, onboarding
- exclude: casino, gambling, console
- 不安点: 難易度調整や再訪導線が短期指標は改善しても、D30では逆効果になる可能性があるのではないか
